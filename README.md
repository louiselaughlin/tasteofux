# Taste of UX

`tasteofux` is a Codex skill for designing, prototyping, or building a product feature, screen, or user flow. It uses your brief and earlier answers to ask only the questions that still affect the design.

It covers who the feature is for, what information it should show, how people get to it and what they can do next, and how to tell whether it solves the problem. It checks the current project for an applicable design system before asking. If several apply, it asks which to use unless you already chose one.

## Try it

With the skill installed, start a prompt with `$tasteofux`.

> `$tasteofux` Design a mobile screen for library members to collect a reserved book from a self-service locker. Make the locker number and pickup code easy to find.

The skill might ask where members open the screen and what they should do if the code fails. It uses your answers to shape the design and reviews the result against the original problem and any agreed success measures.
